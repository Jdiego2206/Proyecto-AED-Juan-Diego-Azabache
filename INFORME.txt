DESCRIPCIÓN DEL TRABAJO
────────────────────────────────────────────────────────────────────────────────
Se implementó una animación visual completa de un Binary Search Tree (BST) usando
la librería Manim. La animación demuestra las operaciones principales de esta
estructura de datos:

1. INSERCIÓN DE NODOS (16 segundos)
   - Se inserta la raíz (50)
   - Se insertan 9 valores adicionales: 30, 70, 20, 40, 60, 80, 10, 25, 35
   - La animación muestra cómo se cumplen las propiedades de BST en cada inserción
   - Colores: Azul (raíz), Verde (nodos nuevos)

2. BÚSQUEDA EXITOSA (10 segundos)
   - Se busca el valor 25
   - Se muestra el recorrido desde la raíz hasta encontrarlo
   - Resaltado en amarillo durante búsqueda, verde cuando se encuentra

3. BÚSQUEDA FALLIDA (8 segundos)
   - Se intenta buscar el valor 15
   - Se muestra que el árbol no contiene este valor
   - Resaltado en rojo cuando falla la búsqueda

ESTRUCTURA DE DATOS: BINARY SEARCH TREE
────────────────────────────────────────────────────────────────────────────────
Definición:
Un Binary Search Tree es un árbol binario que cumple la propiedad BST:
  - Para cada nodo N, todos los valores en su subárbol izquierdo < N
  - Todos los valores en su subárbol derecho > N

Ventajas:
✓ Inserción, búsqueda y eliminación eficientes (O(log n) promedio)
✓ Datos ordenados implícitamente
✓ Implementación simple y flexible

Desventajas:
✗ Puede degradarse a O(n) en peor caso (árbol degenerado)
✗ No autobalanceable en esta versión básica
